# qoqofront

Сайт QoQo и внутренняя система учёта продаж.

## Стек

- React 19, TypeScript, Vite
- Material UI v9, фирменная палитра из брендбука
- TanStack Query — работа с API и автообновление списков
- React Router — маршрутизация и защита разделов по ролям
- axios — HTTP-клиент с подстановкой JWT
- oxlint — линтер

## Запуск

```bash
npm install
npm run dev
```

Откроется http://localhost:5173. Запросы на `/api` и `/media` Vite проксирует
на `http://localhost:8000`, поэтому бэкенд должен быть запущен параллельно,
а `VITE_API_URL` в разработке можно оставить пустым.

## Команды

```bash
npm run build     # проверка типов + продакшен-сборка
npm run lint      # oxlint
npm run preview   # локальный просмотр собранной версии
```

## Сборка для боевого контура

`VITE_API_URL` задаёт адрес API и попадает внутрь бандла, поэтому после его
изменения нужна пересборка. В разработке переменную можно не задавать — Vite
проксирует `/api` и `/media` на localhost:8000. Развёртывание на Vercel описано
в [DEPLOY.md](../DEPLOY.md).

## Язык и тема

Интерфейс переключается между русским и казахским, оформление — между светлой и
тёмной темой. Оба выбора запоминаются в браузере, переключатели стоят в меню
системы, в шапке сайта и на странице входа. Язык по умолчанию берётся из
настроек браузера, тема — из настроек операционной системы.

Словари лежат в `src/i18n/`: русский файл задаёт тип `Dictionary`, и казахский
обязан совпасть с ним по составу ключей — иначе сборка не пройдёт. Отдельной
библиотеки нет: `useT()` отдаёт словарь текущего языка, а строки с подстановкой
объявлены функциями, поэтому опечатка в ключе — ошибка типов, а не пустая
строка на экране.

Смена языка перемонтирует поддерево: форматирование чисел и дат живёт вне
React, и так на экране не остаётся строк, посчитанных в прошлой локали.

Числа, суммы и даты пишутся по казахстанскому формату на обоих языках —
`05.07.2026` и `4 632 810 ₸`: это конвенция страны, а не языка. Названия
месяцев берутся из словаря, а не из `Intl`, потому что данные локали `kk` есть
не в каждом браузере — без них Intl молча скатывается к `07/05/2026` и «KZT».

Переводится только интерфейс. Содержимое главной страницы из CMS и
наименования в справочниках хранятся в базе на том языке, на котором их
завели, и от переключателя не зависят.

Тёмная тема — не инверсия светлой: у неё свои ступени фирменной зелени,
подобранные к тёмной подложке (`colorSchemes` в `src/theme.ts`). Фирменный
`#00533B` на тёмном фоне почти сливается с ним, поэтому столбцы графика и
акценты берут более светлую ступень.

## График продаж

`SalesChart` рисует столбцы обычным SVG — отдельная библиотека графиков ради
одного экрана в зависимости не добавлялась. Ширина берётся у контейнера через
`ResizeObserver`, поэтому столбцы считаются в пикселях и не растягиваются.
Подписи оси времени прореживаются по ширине, значение подписывается только у
пикового столбца, остальные читаются по наведению. Тем, кому график не нужен,
рядом есть переключатель на таблицу.

## Маршруты

`/app/routes` — составление маршрутов и контроль дня, доступно руководителям.
Точки добавляются поиском, порядок обхода задаётся стрелками, дни недели —
переключателями у каждой точки. Ни один день не выбран — точка посещается
каждый день.

Вкладка «Контроль дня» показывает план выбранного представителя рядом с фактом:
результат визита и расстояние от места отметки до точки. «—» вместо расстояния
означает, что координат нет и проверить нечем, а не нарушение.

`/app/route` — тот же план глазами представителя: отметка «Я на месте»,
завершение визита с результатом и ссылка в навигатор. Карта не подключалась —
навигатор у представителя свой.

Геолокация в браузере требует HTTPS: на localhost работает, в бою нужен
сертификат, иначе координаты не придут и геопроверка выключится.

## Офлайн и установка на телефон

Приложение устанавливается на домашний экран (PWA) и открывается без сети.
Service worker кэширует только оболочку; данные держит `src/lib/offline.ts` в
IndexedDB — так видно, что именно доступно офлайн, и в кэш не попадают ответы
API, полученные под другим токеном.

Справочники (номенклатура, точки, контрагенты, договоры, склады, единицы)
обновляются при каждом выходе в сеть. Заявка, оформленная без связи, ложится в
очередь и уходит сама, когда связь появится; полоса состояния показывает,
сколько заявок ждут отправки.

**Идемпотентность.** Идентификатор заявки генерирует клиент и отправляет его
серверу. По нему сервер узнаёт повтор и возвращает уже созданную заявку. Без
этого потерянный ответ при плохой связи плодил бы дубли: клиент повторяет
запрос, а на сервере появляется вторая заявка. Проверено: три отправки одного
идентификатора создают одну заявку.

Ограничения: нужен HTTPS (на localhost работает); в iOS Safari нет фоновой
синхронизации — очередь уходит, пока вкладка открыта. Иконку приложения можно
заменить, загрузив свою в разделе «Настройки».

## Печатные формы

`/print/:kind/:id` — заявка, накладная на отпуск и счёт на оплату. Формы
открываются отдельной вкладкой без бокового меню и печатаются средствами
браузера: серверный рендерер PDF не подключался, чтобы не тянуть библиотеку и
не упаковывать кириллические шрифты. Сохранить в PDF браузер умеет сам.

В накладной показывается фактически отгруженное количество, если склад его
проставил, — в остальных формах заказанное. Сумма прописью считается на клиенте
(`src/lib/amountInWords.ts`): данные для печати и так уже там.

Логотип в шапке всегда светлый, независимо от темы интерфейса: документ
печатается на белой бумаге.

## Логотип

Компонент `Logo` берёт файл из настроек системы, если администратор его загрузил,
иначе показывает фирменный логотип из `src/assets/logo.svg`. В тёмной теме
подставляется вариант для тёмного фона, а если он не загружен — основной
перекрашивается в белый. Чтобы заменить
логотип везде, достаточно загрузить файл в разделе «Настройки» — пересборка не нужна.
