# qoqofront

Сайт QoQo и внутренняя система учёта продаж.

## Стек

- React 19, TypeScript, Vite
- Material UI v9, фирменная палитра из брендбука
- TanStack Query — работа с API и автообновление списков
- React Router — маршрутизация и защита разделов по ролям
- axios — HTTP-клиент с подстановкой JWT
- oxlint — линтер

## Запуск

```bash
npm install
npm run dev
```

Откроется http://localhost:5173. Запросы на `/api` и `/media` Vite проксирует
на `http://localhost:8000`, поэтому бэкенд должен быть запущен параллельно,
а `VITE_API_URL` в разработке можно оставить пустым.

## Команды

```bash
npm run build     # проверка типов + продакшен-сборка
npm run lint      # oxlint
npm run preview   # локальный просмотр собранной версии
```

## Разделы

| Адрес | Кто видит |
| --- | --- |
| `/` | Главная страница, собирается из блоков CMS |
| `/login` | Вход для сотрудников |
| `/set-password?token=…` | Установка пароля по ссылке из письма |
| `/app` | Сводка: счётчики заявок и последние заявки |
| `/app/orders` | Заявки со вкладками по статусам |
| `/app/orders/new` | Приём заявки — администратор, директор, торговый представитель |
| `/app/warehouse` | Экран склада, обновляется каждые 10 секунд |
| `/app/refs` | Справочники |
| `/app/users` | Сотрудники и приглашения — только администратор |
| `/app/content` | Редактор главной страницы, новости и акции |
| `/app/settings` | Логотип и реквизиты — только администратор |

## Логотип

Компонент `Logo` берёт файл из настроек системы, если администратор его загрузил,
иначе показывает фирменный логотип из `src/assets/logo.svg`. Чтобы заменить
логотип везде, достаточно загрузить файл в разделе «Настройки» — пересборка не нужна.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/App.tsx` | Провайдеры: тема, TanStack Query, авторизация, роутер |
| `src/router.tsx` | Маршруты и ограничения по ролям |
| `src/theme.ts` | Тема MUI и фирменные цвета |
| `src/api/` | Клиент, типы и хуки запросов |
| `src/auth/` | Контекст авторизации, хранение токена |
| `src/components/` | Layout, логотип, карточка заявки, защита маршрутов |
| `src/pages/public/` | Лендинг, вход, установка пароля |
| `src/pages/app/` | Внутренняя система |
| `src/pages/app/references/config.ts` | Описание полей справочников — из него строятся список и форма |
